Pile QC / Deviation Calculator (BETA)

Objective field QC · Design · GNSS / UTS · Machine

BETA — access required. Neutral field-data calculator: join design with GNSS/UTS as-built and/or machine quality by pile ID, report XY/Z deltas, and compare end-of-drive remaining-Z values recorded from the guidance screen vs the machine-displayed screen against as-built truth. No preferred outcome — numbers only. Load any combination of sources. Plots: GNSS UTS Machine.
