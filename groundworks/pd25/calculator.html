Measure-up prerequisites (quick check)
  • All shots: zero rod height in Siteworks, recorded as control points.
  • Plumb the mast in X and Y before shooting.
  • X slide all the way left (engine bay); Y slide all the way in (rear).
  • Mast foot fully down; machine on a firm, level surface.
  • Do not enter MB/H rod height in Siteworks — use Step 3 below before Calculate.

2 B5 — Mast Pivot / Mast Tilt BETA

Default: use OEM B5 (−1.056 ft / −0.321 m). Measure (BETA): shoot MT, enter flange→X-pin offset; calculator rebuilds B5 and G1/G2/G5/G6. See the target placement help for where to shoot ML/MR/MT.

How do you want to enter B5?

BETA — needs testing Compare measured B5 and rebuilt G1/G2/G5/G6 against OEM before relying on guidance. No special access required. Usually resect to the rear to see MT. Missing MT falls back to OEM.

Positive when ML is left and MR is right. Example: 0.086 m. Enter 0 if ML/MR are already on the X-pin centerline.

3 MB & H rod height (APC for G7)

Groundworks needs antenna phase center (APC), not prism height on the post. If the bracket is angled, use a vertical post or acrylic at APC — see the target placement help.

Measure-up rod used on MB & H?
Rod height entered in Siteworks for MB & H?

Enter post height only — not APC. Calculator adds 4 mm (Zephyr 3 Rugged → APC). P/N 105568 default: 0.200 m / 0.656 ft.

+ HC — hammer center offset (optional T1)

HC appeared in your CSV. If you shot the hammer face instead of center, enter the offset toward/away from ML/MR. Placement photos: target placement help.

Positive (+) — shot on the face, ahead of hammer center (farther from ML/MR). Example: +0.160 m.
Zero (0) — shot at hammer center.
Negative (−) — shot between hammer center and ML/MR.

4 Calculate Groundworks values

Outputs G6, G5, G2, G1, G7, plus B5 when measured, and T5 / T1 when MF / HC are present. Tune T1–T3 on a plumb pile after install — not from COGO alone.

After install — T1, T2 & T3 plumb-pile tuning
  1. Set the machine on a plumb pile and zero guidance in one direction.
  2. Rotate the machine 180°, set back on the same pile, and verify guidance.
  3. Adjust T1, T2, and T3 until error is minimized in both orientations.

If you must enter values much greater than 0.10 ft (30.48 mm), revisit Phase 1 calibrations and your full measure-up before relying on guidance.
