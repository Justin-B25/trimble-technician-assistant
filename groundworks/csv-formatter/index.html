Groundworks CSV Formatter (BETA)

Map columns and export pile CSV for Groundworks import

BETA tool in development. Upload a drill/pile CSV from TBC, Siteworks, or a data collector. Map your columns to the Groundworks import layout, preview the result, then save a semicolon-separated file locally for Groundworks import (v2.0+).

Groundworks export columns (semicolon-separated): ID;X;Y;Z;Orientation;Inclination;Rotation;Length. Orientation, Inclination, and Rotation are in degrees.

Don’t forget the .dc file

The pile CSV is only half of the import. Groundworks also needs the .dc file from the same project on the data collector. Copy it to your USB drive together with the formatted pile CSV before running Groundworks Project Setup.

Siteworks cannot export this for you — copy it from the collector project folder or your Trimble Synchronizer PC folder.

Example project folder (Windows Synchronizer):

C:\Trimble Synchronizer Data\PC\Trimble SCS900 Data\EXAMPLE PROJECT\

In that folder, look for EXAMPLE PROJECT.dc (Type: DC File) in the same directory as AsBuild and Designs.

1. Upload & options

Match the coordinate and length units in your uploaded file before mapping and preview. Choose US FT (US survey foot), International FT, or METRIC to match your Groundworks project.

No unit conversion. This formatter does not convert between metric, US survey feet, or international feet — it treats values as already in the units you select above, which matches how pile coordinates are usually exported from TBC or Siteworks.

2. Map columns

How column mapping works

  1. Choose a CSV column from each dropdown below (works best on phone).
  2. Or drag a blue column header from the preview onto a field (desktop).
  3. Or enter a fixed value when your file does not include that column.
  4. Then click Apply mapping & preview at the bottom of this section.

Map every field yourself — nothing is pre-selected. Required: ID, X, Y, and Z (column or fixed value). Length is optional and defaults to 0 unless you map a column or enter a fixed value.

Orientation / Inclination / Rotation are in degrees. For vertical piles, start with 0 for each and confirm in a test Groundworks import.
X and Y must match your survey convention. Map X to easting and Y to northing from your source file (or the equivalent grid axes your project uses). If these are swapped or mapped to the wrong columns, piles will import in the wrong location. You are responsible for verifying column mapping and checking the export preview before using the file in Groundworks.
