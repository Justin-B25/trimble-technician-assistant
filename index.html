    How to use Technician Assistant

    Technician Assistant groups field tools by product line. From the home screen, open a category, then choose a tool from that category’s list. Many tools include guided workflows, checklists, calculators, and PDF export.

    Getting around

    1. Home — Three categories: Earthworks, Groundworks, and Siteworks Machine Guidance. Tap the Trimble logo to return here from any page.
    2. Category — Each category opens its own page with a blue header and a list of tools for that product line.
    3. Tool — Workflows and calculators open on their own pages. Use All categories or the back link at the top to step back one level.
    4. Machine hubs — Some categories (for example Vermeer PD25 under Groundworks) have a second tool list before the actual workflow or calculator.

    Light & dark mode

    Use the sun/moon toggle in the blue header on any page. Your choice is saved on this device and applies across the app, including category and tool pages.

    Developer feedback

    On the home screen, tap Developer feedback to send an enhancement request, bug report, or question to the app developer.
