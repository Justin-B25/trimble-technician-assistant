Station 4 — ST30 Top Mount training

Use these tools for Bootcamp Station 4. Measure in Siteworks with the naming below, export CSV, then drop into the matching calculator.

ST30 Top Mount Exercise (Activities A & B)

  1. Stage UTS + ST30 + Top Mount; establish station; mark a tip-divot control point.
  2. Siteworks: Measure → Top Mount · Accessory 145 mm · Target Mode Tilt · GeoLock On.
  3. Shoot benchmark as BENCH.
  4. Activity A (tip DOWN / rod upright): TM_UP_0Plumb, TM_UP_5, TM_UP_15, TM_UP_30
  5. Activity B (tip UP / flipped): TM_FLIP_0Plumb, TM_FLIP_5, TM_FLIP_15, TM_FLIP_30
  6. Export Siteworks CSV → open ST30 Top Mount Exercise → enter rod height → drop CSV.
  7. Review tip-down vs BENCH, tip-up vs BENCH, and tip-up vs tip-down.

Battered Pile lab (sono tube)

  1. Stage 12×48 QUIK-TUBE at a known lean.
  2. Name rim shots {PileID}B1–B3 (bottom) and {PileID}T1–T3 (top), e.g. 1001B1 … 1001T3.
  3. Export CSV → open Battered Pile / Batter Calculator → drop CSV for ΔN, ΔE, batter.
