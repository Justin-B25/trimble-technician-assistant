Station 4 — ST30 Top Mount Exercise (Activities A & B)

Measure in Siteworks with the naming below, export CSV, then drop into this calculator.

  1. Stage UTS + ST30 + Top Mount; establish station; mark a tip-divot control point.
  2. Siteworks: Measure → Top Mount · Accessory 145 mm · Target Mode Tilt · GeoLock On.
  3. Shoot benchmark as BENCH.
  4. Activity A (tip DOWN / rod upright): UP0, UP5, UP15, UP30
  5. Activity B (tip UP / flipped): DOWN0, DOWN5, DOWN15, DOWN30
  6. Export Siteworks CSV → enter rod height below → drop CSV.
  7. Review tip-down vs BENCH, tip-up vs BENCH, and tip-up vs tip-down.

Drag a Siteworks point CSV. Deviations are measured − BENCH. Tip-up vs tip-down is tip-up − tip-down at the same tilt. Tip specs (XY|Z mm) use the nearest rod-height row. CSV N/E/Z are converted from the selected coordinate unit (default US Survey Feet) before the mm check.
