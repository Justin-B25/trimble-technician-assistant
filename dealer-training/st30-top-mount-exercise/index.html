Station 4 — ST30 Top Mount Exercise (Activities A & B)

Measure in Siteworks with the naming below, export CSV, then drop into this calculator.

  1. Stage UTS + ST30 + Top Mount; establish station; mark a tip-divot control point.
  2. Siteworks: Measure → Top Mount · Accessory 145 mm · Target Mode Tilt · GeoLock On.
  3. On the tip-divot mark, shoot plumb first: UP0 (Activity A) and/or DOWN0 (Activity B). That 0° shot is the origin.
  4. Activity A (tip DOWN / rod upright): UP0, then UP5, UP15, UP30 — calculator relates the three tilts to UP0
  5. Activity B (tip UP / flipped): DOWN0, then DOWN5, DOWN15, DOWN30 — related to DOWN0
  6. Export Siteworks CSV → drop below (rod height auto-fills from Target Height when present).
  7. Review UP* vs UP0, DOWN* vs DOWN0, and tip-up vs tip-down.

Drag a Siteworks point CSV (US Survey Feet). Linear values are converted to meters; tip deltas are shown in mm so you can compare directly to ST30 tip specs. Tip deltas = measured − UP0 / DOWN0. Tip-up vs tip-down is tip-up − tip-down at the same tilt.

Job & rod height

Tip-spec row is chosen per activity (nearest published height: 0.2 m Top Mount · 1.6 m · 2.0 m). Defaults match Station 4: UP* ≈ 1.55 m pole, DOWN* ≈ 0.145 m Top Mount. CSV Target Height overrides when present.
